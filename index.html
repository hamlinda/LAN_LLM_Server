Ollama Connection & CORS Guide

By default, web browsers prevent web pages from making cross-origin HTTP requests due to security rules (CORS). Since this frontend runs in your browser, it needs permission to talk to your local Ollama server.

1. Ensure Ollama is Running

Confirm that Ollama is active on your machine by opening http://localhost:11434 in a new browser tab. You should see "Ollama is running".

2. Configure CORS (Cross-Origin Resource Sharing)

If the server is running but you cannot connect or load models, you need to enable CORS access for Ollama by setting the OLLAMA_ORIGINS environment variable to "*".

On Linux / macOS (Terminal)

Stop Ollama and restart it with the variable prepended:

OLLAMA_ORIGINS="*" ollama serve

On Windows (Command Prompt / PowerShell)

Close Ollama from the system tray completely. Then run:

set OLLAMA_ORIGINS=*
ollama serve

Or add OLLAMA_ORIGINS with value * to your system environment variables and launch Ollama normally.

3. Verify the Endpoint

If you run Ollama on a custom port or separate server, enter its address in the server URL field at the top of the settings sidebar (e.g., http://192.168.1.100:11434).
